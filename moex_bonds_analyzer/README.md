# moex_bonds_analyzer

Анализ и рекомендации по облигациям на российском рынке через MOEX ISS API.

Консервативные расчёты — без реинвестирования купонов, с учётом налогов и комиссий.

## Установка

```bash
pip install -r requirements.txt
```

Зависимости: `requests`, `pandas`, `numpy`, `scipy`, `pyyaml`.

## Использование

```bash
# Анализ одной облигации по ISIN
python main.py --isin RU000A1090K0

# Анализ портфеля из CSV (колонка 'isin')
python main.py --portfolio bonds.csv

# Топ-5 рекомендаций
python main.py --top 5

# С расширенной аналитикой Cbonds (требуются учетные данные)
python main.py --isin RU000A1090K0 --use-cbonds
```

## Конфигурация

Файл `config.yaml` в папке проекта:

| Параметр | По умолчанию | Описание |
|----------|-------------|----------|
| `tax_rate` | 0.13 | Ставка НДФЛ |
| `broker_commission` | 0.0004 | Комиссия брокера (0.04%) |
| `risk_free_rate` | null | Ключевая ставка ЦБ (null = авто) |
| `investment_horizon_days` | 730 | Горизонт инвестора (2 года) |

Переменные окружения (переопределяют YAML):
- `MOEX_TAX_RATE`, `MOEX_COMMISSION`, `MOEX_RISK_FREE_RATE`, `MOEX_INVEST_HORIZON`
- `MOEX_CBONDS_LOGIN`, `MOEX_CBONDS_PASSWORD`

## Формулы

- **Текущая доходность**: `(Годовой купон / Цена) × 100%`
- **Простая YTM**: `(Чистый доход / Расход) × (365 / дней) × 100%` (без реинвестирования)
- **Эффективная YTM**: решение уравнения `P + НКД = Σ(CF/(1+r)^t)` численным методом
- **Дюрация Маколея**: `Σ(t×PV(CF)) / Σ(PV(CF))`
- **Скоринг**: взвешенная оценка 6 факторов (доходность, кредит, дюрация, ликвидность, защита, налоги)

## Важно

**Данная программа НЕ является инвестиционной рекомендацией.**
Это инструмент расчёта метрик. Окончательное решение принимает пользователь.
Все расчёты консервативны — без допущения о реинвестировании купонов.

## Ограничения

- MOEX ISS API не требует авторизации, но имеет лимиты запросов
- Кэширование (SQLite, 1 час) снижает нагрузку
- Cbonds API — опционально, с демо-доступом Test/Test
- Для --top анализируются бумаги с основной доски TQCB
- Кредитные рейтинги определяются по уровню листинга MOEX (при отсутствии Cbonds)
